Primeiros passos

  1. Para testar, o microfone do aparelho serve; para tocar de verdade, plugue a guitarra numa interface de áudio USB. Use fone com fio: sem fone o som volta pelo microfone e apita; Bluetooth atrasa.
  2. Toque em Ligar. Ajuste Entrada até o medidor ficar verde nas notas fortes. Outros sons: Lista ▾.
  3. Toque num pedal para ligar e desligar, num botão para girar. Arraste para mudar a ordem.
